# OpenApproval

Согласование расходов, снабжения, приказов и оплат через сайт и Telegram.
Маршруты согласования, история решений, вложения и транши хранятся вместе
с заявкой.

**Статус: beta для самостоятельного развёртывания.** Перед использованием
с рабочими данными проверьте права, резервное копирование и интеграции
на отдельной установке. Хостинг и сопровождение в поставку не входят.

## Возможности

- Расходные заявки, снабжение и управленческие документы.
- Последовательное согласование, возврат на доработку и история версий.
- Отдельные этапы поставки, финансового согласования и оплаты траншей.
- Доступ по ролям и проектам; восстановление маршрута после отзыва доступа.
- Вложения и подписи в private storage, формирование PDF.
- Уведомления в Telegram; Google Sheets и Sentry подключаются отдельно.

Основа: PHP 8.2+, Laravel 12, Inertia, Vue 3, TypeScript и Tailwind CSS.
Локально используется SQLite; production рассчитан на PostgreSQL 16.
Task Tracker отключён по умолчанию и не входит в поддерживаемый продукт.

## Локальный запуск

Нужны Composer 2, **Node.js 22.12+** и npm, PHP 8.2+ с расширениями
`bcmath`, `curl`, `dom`, `fileinfo`, `gd`, `intl`, `mbstring`, `pdo_sqlite`,
`xml`, `xmlreader`, `xmlwriter` и `zip`.

Скачайте ZIP с исходниками из репозитория и распакуйте. Откройте терминал
в каталоге с `composer.json`:

```bash
composer setup
php artisan db:seed
php artisan admin:bootstrap
php artisan serve --host=127.0.0.1 --port=8000
```

Откройте **http://127.0.0.1:8000**. Bootstrap запросит имя и телефон
администратора, один раз покажет временный пароль и потребует сменить его
при входе. Публичная регистрация на сайте выключена.

`composer setup` предназначен для новой копии: создаёт `.env`, отдельную
SQLite-базу, устанавливает зависимости, выполняет миграции и собирает frontend.
Первое скачивание PHP-зависимостей может быть долгим; стандартный таймаут
Composer для этой команды отключён.
При существующем `.env` команда останавливается, ничего не перезаписывая.
`db:seed` создаёт роли, демонстрационный проект и отделы без пользователей,
подписей и общих паролей. Bootstrap не заменяет существующего администратора.

Если первая установка прервалась после создания `.env`, продолжите вручную:
`composer install`, `npm ci`, `php artisan migrate`, `npm run build`.
Перед миграциями выполните `php artisan key:generate`, **только если `APP_KEY`
в новой `.env` ещё пуст**. Ключ существующей установки менять нельзя.

Для разработки после установки запустите `composer dev`. Для фоновых
напоминаний в отдельном терминале нужен `php artisan schedule:work`.
Telegram для входа на сайт и локального знакомства с интерфейсом не требуется.

## Самостоятельное развёртывание

[Инструкция](docs/self-hosting.md) описывает Docker, PostgreSQL, HTTPS,
Telegram, фоновые процессы и внешние утилиты для документов.
Платные аккаунты интеграций не обязательны для локального запуска.

Основные настройки перечислены в [.env.example](.env.example).
Не используйте рабочие токены и базу для локальной разработки.
