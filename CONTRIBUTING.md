# Участие в разработке

Спасибо за помощь с OpenApproval. Первая открытая версия имеет статус beta:
интерфейсы и инструкции установки могут меняться.

## Начало работы

Используйте [README](README.md) для установки в отдельную локальную базу.
Не подключайте среду разработки или тесты к рабочей базе, боту или Google Sheets.
Для разработки: `composer dev`. Для проверки фоновых заданий отдельно запустите
`php artisan schedule:work`.

## Ошибки и изменения

В issue укажите шаги воспроизведения, ожидаемый и фактический результат,
версии PHP/Node и тип БД. Используйте вымышленные данные. Удалите токены,
телефоны, подписи и документы из скриншотов и журналов.
Уязвимости направляйте по [SECURITY.md](SECURITY.md).

Присылайте небольшие pull request с описанием проблемы, изменения поведения
и выполненных проверок. Для интерфейса добавляйте снимки телефона и компьютера
с демонстрационными данными. Следуйте [правилам интерфейса](docs/ui-patterns.md).
Не меняйте отключённый Task Tracker в рамках изменений согласований.

## Проверки

```bash
npm run lint:check
npx vue-tsc --noEmit
npm run build
node --test tests/*.test.mjs
php artisan test --filter='^(?!.*Tracker)'
composer audit --locked
npm audit --audit-level=high
```

PHP-тесты используют отдельную SQLite-базу в памяти. CI дополнительно проверяет
PostgreSQL и конкурентные изменения. Миграции, права, работу с файлами и
изменения бизнес-процессов сопровождайте тестом, проверяющим результат.
Существующие настройки `.env` и данные не должны изменяться при установке.
Task Tracker исключён из проверок поддерживаемого продукта; фильтр CI совпадает
с приведённой командой. Отдельный Docker job проверяет сборку production-образа,
первый запуск с PostgreSQL, очередь, scheduler и страницу входа.

Composer оставляет только Google API `Sheets` и `Drive`, необходимые интеграции.
Если добавляете другой Google API, обновите список `google/apiclient-services`
в `composer.json` и переустановите пакет сервисов по инструкции Google Client.

Код распространяется по [MIT](LICENSE). Отправляйте только код и материалы,
которые вы вправе предоставить под этой лицензией.

## Известные предупреждения инструментов

На 21 октября 2026 года `composer audit --locked` и
`npm audit --omit=dev` не сообщают об известных уязвимостях. Полный `npm audit`
содержит шесть предупреждений в инструментах разработки: четыре high
в цепочке `@vue/eslint-config-typescript → fast-glob → micromatch → braces`
и два moderate в `eslint-plugin-vue → postcss-selector-parser`.

Это две причины, распространяющиеся на шесть пакетов:
[braces](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) и
[postcss-selector-parser](https://github.com/advisories/GHSA-rj75-hqrm-r3gf).
Автоматический `npm audit fix --force` меняет совместимость инструментов;
не применяйте его без проверки lint/typecheck/build. CI проверяет production
дерево, а полный аудит нужно пересматривать при обновлении инструментов.
